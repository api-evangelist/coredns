This is a release with bug fixes and some new features added. We now enable HTTP/2 in gRPC service (https://github.com/coredns/coredns/pull/4842). The shuffling algorithm in loadbalance plugin has also been improved to have a more consistent behavior (https://github.com/coredns/coredns/pull/4961).
