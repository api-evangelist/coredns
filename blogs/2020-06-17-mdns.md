Description This plugin reads mDNS records from the local network and responds to queries based on those records. Useful for providing mDNS records to non-mDNS-aware applications by making them accessible through a standard DNS server. Syntax mdns example.com [minimum SRV records] [filter text] [bind address] Examples As a prerequisite to using this plugin, there must be systems on the local network broadcasting mDNS records.
