Description netbox enables reading zone data from a netbox instance. Syntax netbox { url http://10.0.0.2:9000/api/ipam/ip-addresses token youSekretAPITokenForNetbox } The plugin will delegate search to the next plugin if a record isn’t found. If a record is found a record is sent and the query processing is stopped.
