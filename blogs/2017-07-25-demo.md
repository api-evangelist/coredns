Description This demo plugin showcases the implementation of source IP based service discovery. It is intended as a boilerplate code, so that anyone that is interested in coredns implementation could build their plugin on top of this demo plugin. This demo plugin and its full code has been walked through in past KubeCon talks Note: In order to add a new plugin, an additional step of make gen is needed.
